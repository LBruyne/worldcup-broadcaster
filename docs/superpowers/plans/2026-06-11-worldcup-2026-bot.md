# 2026 世界杯 QQ 群播报 Bot 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 2022 版世界杯 QQ 播报 Bot 重写为 2026 版：ESPN 数据源、NapCat/OneBot 11 推送、实时事件播报、每日预告/总结（DeepSeek 生成看点与锐评）、systemd 部署。

**Architecture:** Go 单二进制常驻进程。robfig/cron（Asia/Shanghai 时区）触发 23:00 预告与 15:00 总结；watcher 模块按赛程在开球前自动启动 per-match goroutine，轮询 ESPN summary 端点做事件 diff，新事件经格式化后进入串行发送队列推送到 OneBot HTTP（NapCat）。所有抓取数据落盘 JSON，事件去重状态持久化，崩溃重启不重推。

**Tech Stack:** Go 1.22+，robfig/cron/v3，gopkg.in/yaml.v3，lumberjack（日志轮转），标准库 net/http + slog。外部：ESPN site API（免 key），DeepSeek API（OpenAI 格式，deepseek-v4-pro），NapCat（Docker，OneBot 11 HTTP）。

**硬 deadline:** 今晚中国时间 23:00 发出首条预告（开幕战明晨 03:00 墨西哥 vs 南非）。

## 关键外部接口事实（已实测验证）

- ESPN scoreboard: `GET https://site.api.espn.com/apis/site/v2/sports/soccer/fifa.world/scoreboard?dates=YYYYMMDD`
  - `events[]`: `id`, `date`(UTC ISO), `name`, `status.type.{state,detail,completed}`, `competitions[0].competitors[]`（`homeAway`, `score`, `shootoutScore`, `team.displayName`）
  - `dates` 参数语义不明确 → 永远取两个 UTC 日期的并集，再按 `event.date` 转 Asia/Shanghai 过滤
- ESPN summary: `GET .../summary?event=<id>`
  - `keyEvents[]`: `id`, `type.text`（`Kickoff`/`Goal`/`Penalty - Scored`/`Penalty - Missed`/`Own Goal`/`Yellow Card`/`Red Card`/`Substitution`/`Halftime`/`Start 2nd Half`/`End Regular Time`/...），`clock.displayValue`，`participants[].athlete.displayName`（进球者在前、助攻在后），`team.id`
  - 其他键: `headToHeadGames`, `standings`, `rosters`, `leaders`, `gameInfo`, `shootout`
- DeepSeek: `POST https://api.deepseek.com/chat/completions`，OpenAI 格式，`model: deepseek-v4-pro`，thinking 默认开启，body 可带 `reasoning_effort: "high"`，响应 `choices[0].message.content`（`reasoning_content` 忽略）。不支持 temperature 等参数（传了被忽略）。
- OneBot 11 (NapCat): `POST {base}/send_group_msg` JSON `{"group_id":123,"message":"text"}`；`POST {base}/send_private_msg` `{"user_id":123,"message":"text"}`；Header `Authorization: Bearer <token>`。

## 核心算法：事件 diff（internal/watcher/diff.go）

纯函数 `Diff(prev, curr *espn.Summary, seen map[string]bool) []Event`：
- keyEvents 以 `id` 为唯一键；`seen` 来自 store（重启恢复）
- 新出现且 `!seen[id]` 的事件 → 翻译为内部 `Event{Type, Clock, Team, Players, ScoreHome, ScoreAway}`
- 点球大战：`shootout` 数组同样按条目 diff（键 `shootout-<n>`）
- 比分取 diff 时刻的 header competitions competitors score（进球消息要带最新比分）
- 状态机：`status.type.state` `pre→in→post`；`detail` 含 `FT-Pens`/`AET` 用于终场文案

- 规格覆盖：实时事件(含加时/点球)✓ 23:00 预告✓ 15:00 总结✓ LLM 看点/锐评✓ 数据落盘✓ 配置化群号/QQ✓ 日志✓ 告警✓ 测试✓
